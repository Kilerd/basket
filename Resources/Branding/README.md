# Branding

`basket-star.png` — the Basket mascot (a basket star with a woven-basket rim), from the
[IP as Logo](https://visualskills.dev/ip-as-logo) collection (`cdn.ipaslogo.com`,
`logos/e1219efb6b012f0b-basket-star.png`), which is offered free to download and use
commercially. Collection project: [s1dashu/ip-as-logo-skill](https://github.com/s1dashu/ip-as-logo-skill) (MIT).

`AppIcon.icns` is generated from it by `scripts/make-icon.sh` (macOS squircle mask on the
1024 pt icon grid). Regenerate after changing the source image.
